# ChaosSMP 0.1.0

Первый разрабатываемый модуль Chaos SMP для Paper 1.21.11:
- `/setspawn` — установка спавна (только OP / `chaossmp.setspawn`).
- `/spawn` — телепортация с задержкой 5 секунд.
- Отмена телепортации при движении или получении урона.
- Запрет телепортации во время PvP-тега.
- `/stats [ник]` — убийства, смерти, лучшая серия и время игры.
- `/top [kills|deaths|streak|playtime]` — четыре рейтинга.
- Четыре автоматически обновляемых голограммы на спавне.
- SQLite-хранилище, данные сохраняются после перезапуска.

## Сборка на GitHub

1. Создай репозиторий и загрузи **всё содержимое** этого архива в корень репозитория.
2. Убедись, что workflow находится по пути `.github/workflows/build.yml`.
3. Открой вкладку **Actions** и запусти `Build ChaosSMP`.
4. Скачай артефакт `ChaosSMP-...` из завершённого запуска.
5. Помести JAR в `plugins/` сервера Paper 1.21.11 и перезапусти сервер.

Требуется Java 21. Gradle wrapper намеренно не включён: GitHub Actions использует установленный Gradle.

## Настройка

После первого запуска появится `plugins/ChaosSMP/config.yml`.
Вызови `/setspawn` в точке центра спавна. Четыре стенда появятся вокруг неё.
Если нужно изменить расположение, отредактируй `leaderboards.boards` и перезапусти сервер.

## Важно

Это исходный стартовый модуль 0.1.0, а не готовый проверенный JAR. Перед публичным запуском протестируй команды и PvP-правила на тестовом сервере.
